# Core Concepts

Labs for Hello Interview **[Core concepts](https://www.hellointerview.com/learn/system-design/in-a-hurry/core-concepts)** (and the [quick reference](https://www.hellointerview.com/learn/system-design/in-a-hurry/core-concepts/quick-reference)). Cite Alex Xu where it helps. Original notes only.

These are **not** product interviews. Each subfolder explains one idea (every important variant, when it wins) and later a small Docker/Python demo when you prompt that topic.

Prompt by name, e.g. `Networking Essentials` or `caching`. Commit previous work first (`04-commit-before-question.mdc`). Follow `.cursor/rules/12-prepare-a-concept.mdc`.
