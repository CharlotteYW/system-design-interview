Sharding

At 100 writes/s and 50 GB you would keep one database. This page forces two shards so the routing is visible. Even account ids go to shard0. Odd account ids go to shard1. “My orders” reads only that shard. “Every order” can read both shards (scatter) or the recent table written at the same time as the order.
