Caching lab

  1. Click Fetch — MISS (Postgres).
  2. Click Fetch again — L1 (same process, no Redis/DB).
  3. Change the body, Save, then Fetch — MISS with the new text.
  4. Fetch once more so both caches fill, click Drop L1 only, then Fetch — REDIS (L2). Next Fetch is L1 again.

GET is cache-aside (L1 → Redis → Postgres). PUT invalidates. The big line below is the cache result (also sent as header X-Cache).
