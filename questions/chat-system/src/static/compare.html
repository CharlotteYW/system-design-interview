Same chat, two message stores

The left pane is design 1: messages and device_cursors in Postgres. The right pane is design 2: the same two tables in Cassandra. The roster, Redis Pub/Sub, and the chat servers are the same on both sides. Each side has its own data.

  1. Click Online cross server on both sides.
  2. Send 6 messages to lee-kim on both sides. The right partition card grows a second bucket.
  3. Select kim-phone in the mailbox, then click Ack all.
  4. Click Late ack. The left cursor stays put. On the right, the upsert moves it back and the LWT keeps it.
  5. Disconnect kim-phone, send, then connect. Compare the reads in each connect response.
