Key-value store

The load balancer picks a server round-robin. That server is the coordinator. It hashes the key onto the ring and writes three owners. Success is 2 of 3 acknowledgements after each owner’s write-ahead log is on disk. A get that hits this coordinator’s L1 returns from that one server. A miss reads two owners. Each owner checks a bloom filter before opening an SSTable. Absent skips that file.
