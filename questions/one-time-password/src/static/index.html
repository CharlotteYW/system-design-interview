One-time password

Generate stores a hash in Redis, queues the 6 digits, and returns 202 with expires_in (600 seconds, 10 minutes). The digits are not in that response. A worker delivers them to the inbox below, which stands in for SMS or email. Verify runs one Lua script: a match deletes the key, then the API returns 200 { "ok": true }. Five wrong guesses delete the key too. A second check of the same code gets 400 { "ok": false }.

Ask for a code

One new code per destination per 60 seconds. Ten codes per destination per day. About ten generates per IP per minute.

Inbox

This is the phone or the mailbox. It fills only after the worker sends. The generate response stays empty of digits.
